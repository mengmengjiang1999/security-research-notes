# 知识库导航

本目录按“可复用知识优先、时间记录归档”的原则组织。

## 核心内容

1. [主题笔记](topics/README.md)：按技术主题沉淀的方法、工具、代码阅读与排错经验。
2. [文献阅读](literature/README.md)：按研究方向组织的论文笔记。
3. [实践材料](practice/README.md)：CTF 与可复现实验材料。
4. [演示资料](presentations/README.md)：论文分享的 Markdown、图片和 PDF。
5. [研究项目](projects/README.md)：按项目聚合问题定义、方案设计和阶段性材料。
6. [研究日志](journal/README.md)：保留时间线，便于追溯想法和实验过程。
7. [课程笔记](course-notes/README.md)：与研究主线分开的课堂速记归档。

## 维护原则

- 一个条目聚焦一个问题；多个问题拆分后通过相对链接关联。
- 文件名应表达主题，避免 `copy`、临时编号和本地路径等信息。
- 优先保留 Markdown 源文件；PDF 仅作为演示成品或必要附件。
- 提交前检查个人信息、失效的相对链接和意外加入的编译产物。
- 原始日志中的成熟结论应逐步提炼到主题笔记，日志本身保持归档属性。
- 项目分区保留研究语境和阶段性产出；其中的通用结论逐步提炼到主题或文献分区。
